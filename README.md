# Sungold

Full-stack Terreno app generated by [`create-terreno-app`](https://www.npmjs.com/package/create-terreno-app).

## Project structure

- **backend/** — Express/Mongoose API (`@terreno/api`, Better Auth, admin, sync)
- **frontend/** — Expo universal app (`@terreno/ui`, `@terreno/syncdb`, `@terreno/rtk`) for web and iOS
- **macos/** — native SwiftUI menu-bar app and network filter extension
- **browser-extensions/** — browser extensions for page-level rules (not started)
- **docs/** — [architecture](docs/explanation/architecture.md), [decision records](docs/decisions/), how-tos and plans

## Local development

1. **MongoDB replica set** (required for sync/realtime). For local dev, run a single-node replica set and point `MONGO_URI` at it. See the [deployment baseline](https://github.com/TerrenoLabs/terreno/blob/master/docs/explanation/deployment-baseline.md).

2. **Install dependencies**

```bash
cd backend && bun install
cd ../frontend && bun install
```

3. **Configure env** — copy `backend/.env.example` and `frontend/.env.example` to `.env` (or use the generated, gitignored local defaults in `backend/.env` / `frontend/.env`).

4. **Seed login users**

```bash
cd backend && bun run seed
```

Creates `test@example.com` and `admin@example.com` (password `testpassword123`).

5. **Start the stack**

```bash
# Terminal 1 — API (default port 4000)
cd backend && bun run dev

# Terminal 2 — web UI (port 8093)
cd frontend && bun run web
```

After backend route changes, regenerate the OpenAPI SDK:

```bash
cd frontend && bun run sdk
```

## End-to-end tests

With the backend running (`cd backend && bun run dev`):

```bash
cd frontend
bunx playwright install chromium   # once
bun run e2e                        # starts the web app on :8093 if it is not running
```

Tests live in `frontend/e2e/`. Start the web dev server without `CI=1`; that setting turns off file watching, so edits are not picked up.

## Deploy

Read the [deployment baseline](https://github.com/TerrenoLabs/terreno/blob/master/docs/explanation/deployment-baseline.md) first (MongoDB replica set, auth secrets, `EXPO_PUBLIC_*` at build time, `/health`, and more).

### Backend (Docker / Cloud Run)

This repo includes a **consumer** `Dockerfile` at the project root. It builds only `backend/` — not the Terreno monorepo.

```bash
docker build -t sungold-backend .
docker run --rm -p 8080:8080 \
  -e MONGO_URI='mongodb+srv://...' \
  -e BETTER_AUTH_SECRET='...' \
  -e BETTER_AUTH_URL='https://api.example.com' \
  sungold-backend
```

Cloud Run and other platforms set `PORT`; the server listens on that port and exposes `GET /health`.

Step-by-step GCP deploy: [Deploy backend to Cloud Run](https://github.com/TerrenoLabs/terreno/blob/master/docs/how-to/deploy-backend-to-cloud-run.md).

### Frontend (static web)

Set `EXPO_PUBLIC_API_URL` **before** export — it is inlined into the bundle at build time:

```bash
cd frontend
EXPO_PUBLIC_API_URL=https://api.example.com bun expo export --platform web
```

Full walkthrough: [Build for web](https://github.com/TerrenoLabs/terreno/blob/master/docs/how-to/build-for-web.md).

## Default local database name

`MONGO_URI` defaults to `mongodb://127.0.0.1:27017/sungold?replicaSet=rs0` in `backend/.env`.
